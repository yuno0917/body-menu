# ボディメイク メニューメーカー

週の回数・環境・重点部位を選ぶだけで、全身の見た目をバランスよく変える筋トレの8週間メニューを作る Web ツールです。公開先は https://yuno-lab.com/body-menu/ です。

- 種目、セット数、回数、余力、休憩時間を、筋肥大の研究にもとづいて組み立てる
- ジム用と自宅用（ダンベルとベンチ）の種目を用意
- 入力はブラウザ内だけで処理し、サーバーには送信しない

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 入力フォーム・結果・考え方・免責 |
| `evidence.html` | メニューの根拠にした研究のまとめ |
| `tests.html` | ロジックのテスト（ブラウザで開くと結果を表示） |
| `js/body-data.js` | 目標セット数、種目、組み方、8週間の波などの設定値 |
| `js/body-program.js` | メニュー生成ロジック |
| `js/app.js` | フォーム・描画・保存・共有リンク |

設定を変えたら `tests.html` を開き、テストがすべて通ることを確認してください。
